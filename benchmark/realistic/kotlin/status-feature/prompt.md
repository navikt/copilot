Add an endpoint for completing an existing task: `POST /tasks/{id}/complete`, with no request body. A successful request returns HTTP 200 and the task in the existing `id:title:status` format, with status `done`. Completing a task twice must succeed without creating duplicates or changing its title. The updated status must appear in both `GET /tasks/{id}` and `GET /tasks`. Invalid or non-positive IDs must return 400; an unknown positive ID must return 404. Keep the existing GET behavior and response format. Make the change through the repository, service and route layers rather than storing state in the route.
