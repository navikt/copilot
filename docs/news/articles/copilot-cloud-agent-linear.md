Copilot cloud-agent for Linear er nå generelt tilgjengelig (GA). Agenten er en autonom bakgrunnsagent: når du tildeler den et Linear-issue, analyserer den innholdet, jobber selvstendig i et flyktig miljø drevet av GitHub Actions, og åpner en utkast-PR (draft pull request). Fremdriften strømmes fortløpende til Linear-issuets aktivitetslogg, og agenten ber om PR-gjennomgang når den er ferdig.

## Kontroll og tilpasning

Du kan nå styre agenten per issue eller for hele arbeidsområdet:

- **Modellvalg:** Velg hvilken AI-modell agenten skal bruke.
- **Egendefinerte agenter:** Pek på repository-baserte custom agents som matcher teamets arbeidsflyt.
- **Branch-innstillinger:** Sett mål- og arbeidsbranch for pull requesten.
- **Styring underveis:** Nevn Copilot i en kommentar for å gi nye instruksjoner mens agenten arbeider.

## Oppsett og tilgjengelighet

Funksjonen er tilgjengelig for Copilot Pro, Pro+, Business og Enterprise. Installasjon skjer ved å hente appen «GitHub Copilot for Linear» fra GitHub Marketplace — dette krever organisasjonseier-rettigheter i GitHub og admin-rettigheter i Linear-arbeidsområdet.
