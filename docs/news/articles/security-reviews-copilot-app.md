`/security-review` er nå tilgjengelig i public preview i GitHub Copilot-appen. Kommandoen analyserer pågående kodeendringer og returnerer:

- Sikkerhetsfunn med høy konfidens, rangert etter alvorlighetsgrad.
- Handlingsrettede forslag du kan bruke og verifisere uten å forlate Copilot.
- En prioritert oversikt slik at du kan fikse de viktigste problemene før koden lander.

Skanningen er innrettet mot vanlige, høyrisiko-sårbarhetskategorier som injeksjonsfeil, cross-site scripting, usikker datahåndtering, path traversal og svak kryptografi.

Funksjonen komplementerer eksisterende sikkerhetsskanning i Copilot CLI og gir et sammenhengende sikkerhetsnett på tvers av Copilot-flatene.
