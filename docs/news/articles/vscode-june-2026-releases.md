VS Code v1.123 til v1.127, utgitt gjennom juni og tidlig juli 2026, bringer flere store forbedringer til Copilot-opplevelsen.

## Nettleserverktøy er generelt tilgjengelig

Agenter kan nå kjøre en fullverdig nettleser direkte i VS Code — navigere, klikke, skrive, ta skjermbilder og lese konsollfeil. Nettleserverktøyene er på som standard med GA-statusen. DevTools er tilgjengelig i nettleserverktøylinjen for inspeksjon.

Agenten kan bruke dette til å validere frontend-endringer visuelt, sjekke konsollfeil, og verifisere at appen fungerer — uten at du trenger å bytte vindu.

## Parallelle sesjoner og chatter

Du kan nå starte flere Copilot-sesjoner parallelt og la dem jobbe i bakgrunnen mens du fortsetter å kode. Sesjoner kan gjenopprettes ved omstart og navigeres med nettleserhistorikk-mønster (frem/tilbake).

## Kostnadsoversikt per sesjon

En ny «Cost»-badge viser estimert kredittforbruk per chat-sesjon. Utviklere ser forbruket underveis og kan justere arbeidsmetoden deretter.

## Modellvelger fra Marketplace

Model providers kan nå oppdages og installeres direkte fra VS Code Marketplace, slik at du enkelt legger til nye modeller uten manuell konfigurasjon.

## Autopilot-forbedringer

Autopilot er skarpere i å avgjøre når en oppgave er fullført, og bruker færre unødvendige verktøykall.
