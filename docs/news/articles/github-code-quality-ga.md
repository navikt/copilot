GitHub Code Quality er nå generelt tilgjengelig (GA) for GitHub Enterprise Cloud og GitHub Team. Produktet kombinerer CodeQLs determiniske analyse med AI-assistert deteksjon for å fange vedlikeholds- og pålitelighetsproblemer i pull requests. Copilot Autofix foreslår rettelser du kan gjennomgå før merge.

## Nytt siden public preview

- **Organisasjonsbasert aktivering** med dashbord som viser vedlikeholds- og pålitelighetspoeng på tvers av repositorier.
- **Kodedekningsmetrikker** generert fra eksisterende testrapporter (i Code Coverage-seksjonen i repository settings).
- **AI-assistert deteksjon** utfyller CodeQLs regelbaserte analyse med maskinlæringsbaserte funn.

I GitHubs egen utviklingsorganisasjon løser teamene 67,3 % av Code Quality-funn *før* de merger pull requests.
