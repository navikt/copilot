Copilot vision er nå generelt tilgjengelig (GA). Du kan legge ved visuelt innhold i chat-prompter og la Copilot resonnere over det sammen med koden din.

## Hva du kan legge ved

- **Bilder:** JPEG, PNG, GIF og WebP.
- **Dokumenter:** PDF.

## Hvor det virker

Funksjonen er tilgjengelig i tre flater: chat-panelet i VS Code (med lim inn, dra-og-slipp og høyreklikk-vedlegg), nettbasert chat på github.com, og terminalbaserte GitHub Copilot CLI.

## Tilgjengelighet

Copilot vision er tilgjengelig for alle Copilot-abonnenter: Free, Pro, Pro+, Business og Enterprise. Funksjonen krever ingen administrativ konfigurasjon og aktiveres automatisk på alle nivåer. Utrullingen fjerner det tidligere kravet om at Business- og Enterprise-kunder måtte skru på policyen «Editor Preview Features».

For Business- og Enterprise-planer oppbevarer GitHub vedlagte bilder og PDF-er i om lag 24 timer for å levere tjenesten.
