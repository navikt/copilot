**Evaluering: ikke klar til merge.**

- Jackson 3.1.0 og `tools.jackson.*` er brukte riktige koordinater.
- Mye av databind-migreringen er mekanisk, og ingen gamle Jackson 2-importer ble funnet.
- Kritisk risiko: `jackson-datatype-jsr310` ble fjernet. `LocalDate` trenger fortsatt Java Time-modulen i noe som ligner på `tools.jackson.datatype:jackson-datatype-jsr310:3.1.0`; dagens kode kan feile ved serialisering.
- `Ktor 3.0.0` er under minimum 3.4.0 for Jackson 3-integrasjon, men denne tjenesten bruker foreløpig kun `kotlinx-json`.
- Ingen Gradle-wrapper finnes. `gradle build` ble blokkert av Kotlin-konfigurasjonen mot installert JDK 27; Java 17 eller nyere er nødvendig, men kompatibel JDK bør låses.
- Ingen tester ble funnet.
- To separate `dependencies`-blokker bør slås sammen.
- Ingen `JsonNode.map` eller post-builder-mutering ble funnet.
- Æ/ø/å-felt ble ikke funnet, men ingen regresjonstest dekker det.

Neste steg er å verifisere Java Time-modulen, teste round-trip for `LocalDate`, og kjøre build med Gradle-wrapper og støttet JDK.
