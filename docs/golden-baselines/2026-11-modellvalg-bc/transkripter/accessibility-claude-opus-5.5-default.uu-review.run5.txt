## UU-gjennomgang av `StatusPanel.tsx`

Jeg fant 5 brudd på WCAG 2.1 AA. Fire av dem er alvorlige. Jeg har ikke endret filen.

| # | Linje | Problem | WCAG |
|---|---|---|---|
| 1 | `<div onClick>` «Vis detaljer» | Kan ikke nås eller brukes med tastatur. Elementet har ingen rolle og ingen `aria-expanded`. `apen` blir heller aldri brukt, så det finnes ikke noe panel å vise. | 2.1.1, 4.1.2 |
| 2 | `style={{ outline: "none" }}` | Fjerner fokusindikatoren og setter ingenting i stedet. | 2.4.7 |
| 3 | `<span tabIndex={5}>` | `tabIndex` over 0 ødelegger tab-rekkefølgen. Statusteksten skal heller ikke kunne få fokus. | 2.4.3 |
| 4 | `color: red/green` | Statusen vises bare med farge. Ren `red` mot hvit bakgrunn gir 4,0:1 i kontrast, under kravet på 4,5:1. | 1.4.1, 1.4.3 |
| 5 | `<button><TrashIcon /></button>` | Knappen har ikke noe tilgjengelig navn. Skjermleseren leser bare «knapp». | 1.1.1, 4.1.2 |

Mindre funn:
- Endringer i statusen blir ikke lest opp (4.1.3). Bruk `role="status"` hvis verdien endrer seg mens siden er åpen.
- Sletting skjer uten bekreftelse. Legg inn en Aksel-`Modal` (3.3.4).
- `className="p-4 mx-8"` er uproblematisk.

## Forslag

```tsx
"use client";
import { Button, ReadMore, Tag, HStack } from "@navikt/ds-react";
import { TrashIcon } from "@navikt/aksel-icons";

type Props = { status: "ok" | "feil"; onSlett: () => void };

export function StatusPanel({ status, onSlett }: Props) {
  return (
    <div className="p-4 mx-8">
      <ReadMore header="Vis detaljer">{/* detaljer */}</ReadMore>
      <HStack gap="2" align="center">
        <Tag variant={status === "feil" ? "error" : "success"} role="status">
          {status === "feil" ? "Feil" : "OK"}
        </Tag>
        <Button
          variant="tertiary"
          icon={<TrashIcon title="Slett" />}
          onClick={onSlett}
        />
      </HStack>
    </div>
  );
}
```

`ReadMore` styrer `aria-expanded` og tastaturbruk selv. Det løser punkt 1 og 2. `Tag` viser statusen med både tekst og farge, og Aksel-fargene har nok kontrast. Repoet har ikke `package.json` eller `node_modules`, så jeg har ikke kunnet sjekke API-ene mot installert Aksel-versjon. Etter endringen bør du teste med tastatur og axe.
