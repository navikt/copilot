   // aria-activedescendant. Piltaster flytter, Enter/mellomrom velger, slik at onVelg ikke
   // kalles for hvert tastetrykk.
   function StatusListbox({ valg, valgt, onVelg }: StatusListboxProps) {

     const labelId = `${id}-label`;
     const valgtIndeks = valg.findIndex((v) => v.verdi === valgt);
     const [aktivIndeks, setAktivIndeks] = useState(Math.max(valgtIndeks, 0));

                 role="option"

                   color: "var(--ax-text-neutral)",
                   background: erValgt ? "var(--ax-bg-accent-moderate)" : undefined,
                   outline: erAktiv ? "2px solid var(--ax-border-focus)" : undefined,

                 <CheckmarkIcon aria-hidden style={{ visibility: erValgt ? "visible" : "hidden" }}
   />
                 {v.tekst}

       </div>

Jeg har lagt til `StatusListbox` med `role="listbox"` i `StatusPanel.tsx`. Typesjekk og tester er ikke kjørt, fordi repoet mangler `package.json` og installasjon av avhengigheter ble avvist.

**Bryter API-et:** `StatusPanel` krever nå to nye props, `statusvalg` (`{ verdi, tekst }[]`) og `onEndreStatus`. De som bruker komponenten, må sende inn disse.

**Hvordan den virker**
- Fokus blir stående på listen. `aria-activedescendant` viser skjermleseren hvilket valg som er aktivt, og `aria-selected` markerer det valgte.
- Piltastene og Home/End flytter mellom valgene. Enter eller mellomrom velger, slik at du ikke lagrer status for hvert tastetrykk.
- Listen har et synlig navn via `aria-labelledby`, og en fokusring med `--ax-border-focus`.
- Valgt status vises med både hake (`CheckmarkIcon`) og bakgrunnsfarge, ikke bare farge (WCAG 1.4.1).

**Valget du bør vite om:** Egne ARIA-roller er noe vi avtaler før vi bruker dem. Aksel `Select` eller `RadioGroup` gir samme funksjon med innebygd UU og mindre kode å vedlikeholde. Det er mer egen kode å vedlikeholde, og hvis du vil, kan jeg bytte til `Select` eller `RadioGroup`.

**Feil fra før, som jeg ikke rettet**
- `tabIndex={5}` gir feil tabrekkefølge.
- `<div onClick>` kan ikke brukes med tastatur, og `outline: none` skjuler fokus.
- Statusen vises bare med rød eller grønn farge.
- Sletteknappen mangler tilgjengelig navn.
