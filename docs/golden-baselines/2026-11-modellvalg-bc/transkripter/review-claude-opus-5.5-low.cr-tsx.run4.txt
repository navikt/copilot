### Detaljer
Aksel-komponenter løser de fleste blokkerne. `ReadMore` håndterer tastatur, fokus og `aria-expanded`. `Tag variant="error"/"success"` viser status med tekst og tema-tokens. Disse API-ene er ikke sjekket mot installert Aksel-versjon. Sjekk dem med `aksel-builder` før bruk.

```tsx
"use client";
import { Button, ReadMore, Tag } from "@navikt/ds-react";
import { TrashIcon } from "@navikt/aksel-icons";

type Props = { status: "ok" | "feil"; onSlett: () => void };

export function StatusPanel({ status, onSlett }: Props) {
  return (
    <div className="p-4 mx-8">
      <ReadMore header="Vis detaljer">{/* detaljer */}</ReadMore>
      <Tag variant={status === "feil" ? "error" : "success"}>{status}</Tag>
      <Button variant="tertiary" onClick={onSlett}
        icon={<TrashIcon title="Slett status" />} />
    </div>
  );
}
```

Hvis `status` er en sak eller et annet element, bør knappeteksten si hva som blir slettet. Bruk for eksempel «Slett sak 123», ikke bare «Slett status».
