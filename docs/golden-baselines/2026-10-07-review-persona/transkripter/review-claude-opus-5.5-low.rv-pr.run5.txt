

I reviewed the diff between `main` and `vedtak-kafka`. `mise check` was not run because the repo has no mise config or Gradle wrapper, so nothing was compiled or tested.

### Summary
The overall structure is sound: separate consumer, service and repository, constructor injection, and Kotliquery with HikariCP. Three blockers must be fixed before merge: SQL injection, an endpoint with no authentication that returns personal data by fødselsnummer (FNR), and an inbound access policy open to all applications. The JWT setup also does not actually validate tokens, and the Kafka consumer creates duplicate decisions and can get stuck on a bad message.

### Details

**SQL injection (line 23).** Use `queryOf("SELECT * FROM vedtak WHERE fnr = ? ORDER BY vedtaksdato DESC", fnr)`. Combined with the open endpoint, anyone can read or change the whole database.

**Auth.** 🔴 Rød sone: token-validering, gå gjennom denne nøye. Use `jwt { verifier(JwkProviderBuilder(URL(TOKEN_X_JWKS_URI))..., TOKEN_X_ISSUER) { withAudience(TOKEN_X_CLIENT_ID) } }`. Put both vedtak routes inside `authenticate`, and take the FNR from the token's `pid` claim rather than from the request, so users can only see their own decisions. Alternatively, check that the caller is allowed to access the case.

**accessPolicy.** List the specific consumers by application and namespace. With the current wildcard, any app in the cluster can reach the API, which undermines TokenX.

**Kafka.** Make `fattVedtak` idempotent per `soknadId`, for example with a unique constraint and `ON CONFLICT DO NOTHING` that returns the existing decision. Catch deserialization errors per record and send them to a DLQ or log them without PII. Wrap the loop in `try/catch` and `finally { consumer.close() }`, and let a dead thread make `isalive` fail.

The idempotency choice is the main trade-off. A unique constraint on `soknadId` gives exactly one decision per application, but requires a new column and migration. The alternative, deduplicating on Kafka offset, breaks on rebalancing and is not recommended.
